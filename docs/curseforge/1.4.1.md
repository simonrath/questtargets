# Quest Targets 1.4.1

- Controller buttons can be assigned to both targeting actions, alongside keyboard bindings.
- Both targeting actions now appear under Options → Keybindings → Quest Targets.
- Assigning an occupied keyboard key or controller button in the addon's options now asks for confirmation before replacing its existing action.
- Native keybinding changes, including clearing focused-quest bindings, remain saved after UI reloads.
- Quest Targets now appears in the AddOn options immediately after login. Opening settings through the minimap button first is no longer necessary.
- Improved settings reliability. Options that do not apply to the selected button appearance are now greyed out.
- Right-clicking a quest to open the quest log is now prevented during combat.
- Improved the reliability of quest-target map data.

Available for Classic Era, Burning Crusade Classic, Mists of Pandaria Classic, Forever and Retail. Classic, TBC, Mists and Forever packages include QuestieDB 1.0.9.
