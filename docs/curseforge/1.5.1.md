# Quest Targets 1.5.1

- Resize the quest window by dragging its bottom-right corner. Its size and position are saved, and taller windows show more quests.
- Turn the target buttons beside Questie's tracker on or off in the options.
- Adjust the spacing of Questie's target buttons. New settings start at 35 px; existing custom spacing is preserved.
- Improved minimap-button compatibility with minimap managers and button collectors. Left-click opens the quest window; right-click opens the options.
- The installed version now appears in the options heading, while the AddOn list keeps the short name "Quest Targets".
- The modern compass-style master button is now the default for new settings. Existing appearance choices are preserved.

The same download supports Classic Era, Burning Crusade Classic, Mists of Pandaria Classic, Forever and Retail. QuestieDB is not bundled; install it separately on supported Classic/Forever clients if needed.
