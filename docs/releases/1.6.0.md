Quest Targets 1.6.0 adds a configurable targeting bar and ItemTree farming integration.

- Group the Master, RestedXP and ItemTree buttons in a horizontal bar with shared sizing and movement. Reuse the master compass textures with blue and yellow tints for RestedXP and ItemTree.
- Move the RestedXP targeting button from its guide frame to the bar. Keep the existing guide-target behavior and quest fallback.
- Import direct NPC drops from ItemTree’s current Sources view. Save all imported targets for the button and hotkey. Reuse the master targeting pipeline for visible nameplates and paged name searches. Prioritize the current zone and use QuestieDB spawn distances where available.
- Keep the optional character macro for action-bar compatibility. It uses the client’s 255-byte limit. Recognize older generated bodies and normalize line endings before checking ownership.
- Disable both ItemTree hotkey fields while the addon is unavailable. Ship ItemTree integration in the universal archive without bundling ItemTree or QuestieDB.

References used during implementation include Quest Targets’ existing `Core.ClickMacro` and `Proximity.Order`, plus ItemTree’s installed `UI/Tree.lua`, `Core/ViewModel.lua` and `Core/EraSources.lua` for source row structure and creature IDs. XERJ’s local reference index was unavailable.
