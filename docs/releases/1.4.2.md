# Quest Targets 1.4.2

All five flavor ZIPs and the optional minimal ZIP contain only QuestTargets runtime files.
The packager no longer downloads or embeds QuestieDB. The CurseForge publisher
rejects any additional addon directory for every flavor, including QuestieDB.
Client interface pins and optional addon load ordering are unchanged. QuestieDB
remains a separately installed data provider for non-Retail clients; Retail uses
its native quest log. CurseForge dependency configuration is managed manually by
the project owner after this release.

Player notes: docs/curseforge/1.4.2.md. GitHub assets: five flavor ZIPs and SHA256SUMS.txt.

Reference: XERJ retrieval for LibQuestieDB was attempted but XERJ is not installed
in this environment. Local references: QuestTargets/QuestTargets.toc OptionalDeps,
QuestTargets/Database.lua provider detection, and tools/publish_curseforge.py
verify_asset. No Lua runtime behavior or WoW API integration changed.

Validation: all 199 automated tests passed without skips, including external
QuestieDB integration, all five addon-only builds and publisher rejection of
bundled providers. No live-client test was performed.
