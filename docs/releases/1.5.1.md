Quest Targets 1.5.1 adds a resizable quest window and restores optional Questie tracker controls.

- Resize width and height with the bottom-right grip; save dimensions and position, adapt text widths and display 2–20 quest rows. Combat guards defer interrupted resize completion until combat ends.
- Restore the Questie tracker-button toggle and add configurable horizontal spacing (-40 to 80 px). Default spacing is 35 px, with saved values preserved. Both options disable when Questie is unavailable.
- Replace the custom minimap button with LibDBIcon and a LibDataBroker launcher, including embedded dependencies and upstream notices/licenses. Migrate the old position from radians to LibDBIcon degrees and retain visibility preferences.
- Show installed version metadata only in our options heading; preserve the plain sidebar category name. Use a scoped DisplayCategory posthook without dynamic category-name callbacks.
- Default new profiles to the modern master appearance; preserve explicitly saved classic appearance.

One universal QuestTargets ZIP supports all five client flavors and includes the minimap libraries. QuestieDB remains separate, as in 1.5.0.

Validation: 206 automated tests passed, including combat resize behavior, saved size restoration, default migration, all five native settings configurations, the real embedded library load path, tracker integration and package contents. WoW MCP checked changed APIs and resize textures. Native UI rendering and compatibility with individual minimap managers still require in-client testing; no universal taint-freedom claim is made.
